🐧 Penguin Desktop

Phase 2b: Tauri Shell

This is the Tauri shell wrapping the penguin-desktop-core. It provides authentication and API proxying for the hub.

Phase 3 (Coming):

The published webui will be bundled as the frontend in Phase 3. For now, this placeholder will be replaced with the real React app.

frontendDist in tauri.conf.json points to where the built frontend will be served.

Tauri Commands:
  • login(email, password, hub_url) — Authenticate
  • logout() — Sign out
  • api_request(method, path, body) — Proxy API calls
  • oauth_start(platform, hub_url) — Begin OAuth flow
  • oauth_complete(code, state_param, stored_state) — Complete OAuth callback
Deep-Link:

The app listens for waddles://oauth/callback?code=...&state=... to complete OAuth flows via system browser.
